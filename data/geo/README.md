# Geometrie

Verwaltungsgebiete 1:250 000 mit Einwohnerzahlen (VG250-EW), Stand 31.12.
© GeoBasis-DE / BKG 2026, [dl-de/by-2-0](https://www.govdata.de/dl-de/by-2-0).

Die Angabe muss jede Veröffentlichung mitführen, die diese Geometrien zeigt.

Übernommen aus dem Schwesterprojekt
[hexagonalmap](https://github.com/bagruber/hexagonalmap); erzeugt mit dessen
`scripts/fetch-vg250.py`. Hier liegt eine Kopie statt eines Verweises, damit die
Seite auch dann zeichnet, wenn dort etwas umgeräumt wird.
